# Senior React Developer

We build web products for clients and need a senior frontend engineer to own our React codebase and design system.

## What you'll do
- Build accessible, fast UI in React and TypeScript.
- Own and extend a component library / design system used across products.
- Work with Next.js (App Router, server components) and modern data fetching.
- Write tests (unit and end-to-end) and keep Core Web Vitals healthy.
- Mentor other frontend engineers and review their code.

## What we're looking for
- 5+ years of professional React experience.
- Strong TypeScript.
- Shipped accessible UI (WCAG AA) in production.
- Experience building or maintaining a design system or shared component library.
- Testing discipline (Jest/Vitest, Testing Library, Playwright or Cypress).
